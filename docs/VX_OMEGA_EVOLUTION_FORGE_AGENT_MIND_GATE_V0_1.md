# VX Ω Evolution Forge — Agent–Mind Engineering Gate v0.1

Status: IMPLEMENTED candidate for offline assessment only. Tests NOT_RUN; no live integration verified.

## Architecture
VAIXLNS canonical governance -> Discovery Router -> VX Agent–Mind Registry -> isolated candidate generation -> PCS-001 evidence/approval -> runtime admission (future, not wired).

Each agent has exactly one explicit VX mind identity for its primary domain, with optional specialist consultation carried as separately auditable requests. A 'mind' is a bounded capability + connector identity, NOT a model session or independent policy authority. No automatic model assignment by name.

| Mind domain | Agent purpose | Required evaluation |
|---|---|---|
| RESEARCH | source discovery | provenance, factuality, uncertainty |
| ENGINEERING | code and designs | reproducible tests, static analysis |
| MATHEMATICS | formal analysis | proof or independent numerical check |
| SIMULATION | scenario studies | seeds, repeatability, counterexamples |
| VERIFY | independent assessment | conflict-of-interest separation |
| FINANCIAL | financial analytics | accuracy, risk, zero transactions |
| DATA | datasets | rights, privacy, lineage, quality |
| SECURITY | adversarial analysis | sandbox, no secret access |

1. Compare existing implementations, avoid a new sovereign repository.
2. Verify sources, license and model-provider permissions.
3. Confirm registered model connector, live probe, isolation and typed tool contracts.
4. Validate authorization independently of the model's response; all consequential operations deny by default.
5. Run regression and adversarial tests; run PCS-001 in the canonical VAIXLNS repository.
6. Produce CI test receipts, reproducible benchmark results, SHA-256 manifest and review of all external side effects.
7. Obtain explicit release approval. Protect project.genome and Ω.000.
8. Never treat hashes alone as signatures, authenticity or proof of correct behavior.

This release exposes only a pure function that assesses agent/mind manifests. It deliberately has no network calls, invocation bridge, loader side effects or automatic activation. The outcome ELIGIBLE_FOR_INDEPENDENT_VERIFICATION is not an authorization to run.
